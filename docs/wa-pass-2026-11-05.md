## Stack and commands

Static, dependency-free PWA on GitHub Pages (`index.html` + `transit.js` + `sw.js` + JSON datasets).
No build step and no linter; the "build" gate is the test suite.

| What | Command |
|---|---|
| All offline checks | `sh scripts/check.sh` (node unit + data suites, Python script tests, timetable freshness) |
| Browser suite | `sh scripts/check.sh --e2e` (17 Playwright specs) |
| Deploy | push to `main` → `.github/workflows/pages.yml` (tests, stage, deploy, verify live `BUILD`) |
| Local serve | `python3 -m http.server` |
